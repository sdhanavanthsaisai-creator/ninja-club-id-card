# 🥷 Ninja Club ID Card

An interactive, single-file **Ninja ID card** web page for the Coding Ninja Club — member dossier Nº 001, **Dhanavanthsai**.

🔗 **Live:** https://ninja-club-id-card.vercel.app/

## ✨ Features

- 🖥️ **Boot sequence intro** — terminal-style boot log with progress bar (click to skip)
- 🖱️ **HUD cursor** — custom crosshair-style cursor with contextual action tags
- ✍️ **Scroll-drawn stroke** — a path that draws itself as you scroll
- 🌗 **Reality-layer theme switch** — flip between two visual realities (light/dark) via toggle or keyboard shortcut
- 🎴 **Flippable 3D Ninja ID card** — front and back with holographic shine, barcode, QR block and signature
- 📉 **Perspective text scroll** — 3D-tilted headline that straightens as you scroll
- 📸 **Render viewport** — surveillance-style portrait frame with scanbar, glitch effects and a "VERIFIED" stamp
- 📊 **Skill modules** — animated proficiency bars for DSA, C, competitive programming and front-end
- 🎞️ **Ticker, grain overlay, toasts & entrance animations** — pure CSS/JS, zero frameworks

## 🧰 Tech

Pure **HTML / CSS / JavaScript** in a single `index.html` — no build step, no frameworks, no dependencies. Fonts are loaded from Google Fonts (Unbounded + IBM Plex Mono).

## 🚀 Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## ☁️ Deployment

Deployed on **Vercel** — every push to `master` triggers an automatic production deployment.
